# Fractions Plugin

Interactive pizza fraction visualizer for Photographic Dictionary.

## Features

- **SVG Pizza**: Rendered on a white plate with dough crust, tomato sauce, cheese, and randomized toppings (pepperoni, site-purple olives, site-green capsicum, yellow pineapple).
- **Fraction Controls**: Radio buttons for common fractions (`1/2`, `1/4`, `1/3`, `2/3`, `3/4`, `1/6`) with full names.
- **Animated Cuts & Fades**: Animated line cuts slicing the pizza according to the denominator, followed by slice-by-slice fading overlays revealing the plate underneath.
- **Host Contract Compliance**: Scoped under `#plugin_fractions`, max height 250px, IIFE boot pattern, settings parsing, and host color utilities.
