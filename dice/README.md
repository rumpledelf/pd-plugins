# Dice

Tap either die (or the space around them) to roll both. Space/Enter also rolls. Two independent random results are chosen before tumbling; the total appears after both dice settle. The top faces score.

Faces and circular pips are genuinely projected from a rotating 3D cube. Opposite faces sum to seven. Final rotations are exact quarter turns, with independent random yaw; reduced motion uses a brief static transition. No libraries, network calls, or extra game controls.

Test at `http://localhost:8080/plugin-tester.html?plugin=dice`.
