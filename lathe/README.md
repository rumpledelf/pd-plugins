# Lathe

Start the lathe, then drag on the stock to position the blue cutting tool. The closer the tool is to the spindle centre, the deeper it cuts. Both sides change symmetrically because the workpiece rotates. Tool movement above the centre is mirrored to the lower cutting side.

Keyboard: focus the activity; arrow keys move the tool, hold Space to cut. Start/Stop and New blank are ordinary buttons. Cuts cannot add material or reduce the radius below 10 units. Stopping preserves the shape; New blank restores it. Reduced motion slows rotation and omits shavings.
