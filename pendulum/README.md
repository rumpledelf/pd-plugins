# Pendulum

Drag the bob and release. Arrow keys lift the focused bob; Space or Enter releases it. A sine restoring force and velocity-dependent damping produce natural oscillation and a longer settling time for a larger release. Animation ends when the pendulum settles or the plugin is detached. Motion is the instructional content and only starts on deliberate input; no autoplay or decorative trails.
