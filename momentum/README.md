# Momentum

Choose 1 kg or 3 kg for each trolley. Set the speed slider and click or tap
Push to launch the trolley. More loaded blocks indicate more
mass. Spring bumpers produce a one-dimensional collision with restitution 0.9:
total momentum is conserved across impact, while some kinetic energy is lost.
Floor resistance and the track's end stops subsequently bring the trolleys to
rest; those external forces do not conserve the trolleys' momentum.

Reset works while moving. Controls lock during a run. No shine or focus effects,
no dependencies. 248px maximum height. Essential motion remains visible under
reduced-motion settings; there are no decorative animations.

Test: http://localhost:8080/plugin-tester.html?plugin=momentum

Run saved checks with `node momentum/momentum.test.cjs`.
