# Volume

Starts blank. Choose box, cylinder, sphere, enter positive dimensions, and calculate. Only the selected shape's dimensions are required.

Units: cm, m, in, ft. The grouped selector converts entered measurements and an existing result; it does not relabel numbers. Canonical dimensions are stored in metres and preserved across switches, avoiding cumulative rounding. Display uses 12 significant digits. Results use cubic units. Nonfinite, zero, and negative dimensions are rejected.
