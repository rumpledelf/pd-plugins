# Sort

Five Russian dolls to arrange in either ascending or descending size order. Drag a doll and its neighbours make room, with gaps based on their widths. All five wiggle when sorted. Space/Enter picks up and puts down a focused doll; arrows move it, Escape restores its original position. Shuffle starts another arrangement.

Adapted from the supplied `russian-dolls-loader-clearance.html` artwork using the documented host palette. Respects reduced motion.

Test: `http://localhost:8080/plugin-tester.html?plugin=sort`.
