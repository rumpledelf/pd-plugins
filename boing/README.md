# Boing

A spring toy with a grounded lower coil. Drag the top loop up, down or sideways and let go. Twelve coupled spring masses propagate displacement down the coil; damping settles it. Compression contacts prevent adjacent coils passing through each other. Integration uses steps of at most1/240second.

Each loop, including the top rim, tilts with the local bend. The spring recoils toward a compressed resting stack, overshoots and rebounds. Releasing during a drag preserves the hand's recent velocity; pausing before release gives a stationary release.
The initial and reset shape is compact, with 3.5-unit coil spacing leaving small visible gaps between the wires. Recoil contacts at 2.5-unit spacing bounce without allowing coils to pass through the stack.

Keyboard: focus top coil, arrows stretch/tilt, Space or Enter releases, Escape resets. Pointer cancellation releases safely. Reduced motion lets the spring stretch with direct input and restores it without wobble.

Flat host-blue wire, no shine or focus colour changes. Grounding shadow remains fixed. Visible height248px.
