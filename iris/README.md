# Iris diaphragm

Tap the diaphragm or Open/Close to animate its eight blades. The aperture slider allows slow inspection and interrupts an animation immediately. Keyboard Enter/Space activates the diaphragm; the range input retains native keyboard controls. Reduced motion uses the target state immediately.

This is a simplified iris illustration, not a camera exposure simulation. Straight blade edges pivot at fixed points on the rim, with neighboring blades covering their hidden portions. Their intersections form an octagonal opening at every setting; the edges stay straight as it opens and closes. Neutral flat artwork, no glass shine or focus colour changes. The `/i/iris` page is metadata only; host placement remains the host's decision.

Local test: `http://localhost:8080/plugin-tester.html?plugin=iris`.
