# Magnify

Drag the magnifying glass over the small bug. The lens reveals a clipped 3× view aligned to the bug’s fixed position; the bug smiles and waves when the glass reaches it. Move away to end its greeting.

Keyboard: focus the activity and use arrow keys; Shift moves faster. Pointer capture supports touch and dragging outside the lens. Reduced motion replaces waving with a still raised hand. Activity height is 250px.
