# Open and close

Click the panel door to swing it open or shut. Enter and Space work when focused; rapid clicks smoothly reverse its movement. Keyboard focus highlights the handle. Motion is shortened with reduced-motion preferences.

250px activity. No dependencies. Default page /o/open; the same module can be mounted on the close page by the host.
