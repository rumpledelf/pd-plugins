# Lava Lamp

A continuous, control-free lava lamp animation. Soft wax blobs rise, slow near
the top, sink, and rejoin the pool at the base. SVG filtering blends nearby
blobs into soft connections that separate as the blobs drift apart.

The compact 250px illustration uses flat grey artwork and no external assets.
Motion pauses in hidden tabs. Reduced-motion preferences show a still lamp.
This is an illustration with varied motion cycles, not a fluid simulation.

Local test: `http://localhost:8080/plugin-tester.html?plugin=lava-lamp`.
