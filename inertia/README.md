# Inertia

Push starts a trolley and ball moving together. The trolley hits a fixed stop;
the ball retains its horizontal speed, moves beyond the deck, falls, bounces
and rolls to rest. Reset works throughout. This is an idealized low-friction
deck demonstration, not a claim that inertia is a force. Floor resistance and
inelastic landing eventually stop the ball. Reduced motion omits landing bounces.

Flat artwork, moving wheel markings, no focus effects or shine. Maximum height
246px. No host changes or dependencies.

Test: http://localhost:8080/plugin-tester.html?plugin=inertia

Run saved checks with `node inertia/inertia.test.cjs`.
