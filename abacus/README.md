# Abacus

A four-column soroban for exploring numbers from 0 to 9,999. A bead counts only when moved towards the dividing bar. Each upper bead adds five of its column's units; each lower bead adds one. Columns represent thousands, hundreds, tens and ones. Moving a lower bead also moves the beads between it and the bar. Carrying is manual, as on a physical abacus.

Tap a bead or drag it up/down. Keyboard: Tab between beads, arrows move up/down, Space/Enter toggles. The total and selected column's calculation update together. Reset resets every bead. Flat host-coloured beads, neutral frame, no shine or focus colour changes. No dependencies.

Test through `http://localhost:8080/plugin-tester.html?plugin=abacus`.
